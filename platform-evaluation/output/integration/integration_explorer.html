How to read this page. Internal people, positions and pay are invented by a seeded generator and are not calibrated to EDW. Every SUCSS-class to O*NET link is an unreviewed machine suggestion. Synthetic Campus 1/2/3 are assigned to UIUC/UIC/UIS only so public context can attach. OEWS wages describe an occupation's labour market, not civil-service class pay. Suppressed public values stay blank, never zero.
