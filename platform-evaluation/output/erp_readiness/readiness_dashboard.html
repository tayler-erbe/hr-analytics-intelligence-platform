How to read this

  • Rule score = 1 when no entity fails. Otherwise it is 1 − (failure rate ÷ severity tolerance), with a floor of 0. Tolerances: critical 0, high 0.1 %, medium 0.5 %, low 2 %. Domain score = the severity-weighted mean of rule scores (weights 5/3/2/1). This is a triage measure. It does not guarantee quality.
  • Reconciliation: match means legacy = target within tolerance. Explained means the gap equals the documented load rejections, each tied to a rule ID. Unexplained means a converter defect or an undocumented loss. M1 contains a converter defect that was planted on purpose: one org is missing from the org crosswalk and silently defaults to UNMAPPED. The source data-quality rules cannot see it, and reconciliation does.
  • Mock cycles follow peer practice: Richmond converted Banner data into Workday four times. The defect counts in each cycle are simulated remediation, not a forecast.
